3. Cloud Hosting and Infrastructure (AWS)

This website is hosted externally using Amazon Web Services (AWS) (AWS Amplify Hosting and Amazon CloudFront). The personal data collected on this website is stored on the hoster's servers. This primarily includes IP addresses, technical logs, and metadata.

Legal Basis: The use of AWS is based on Art. 6 (1) (f) GDPR. We have a legitimate interest in the most reliable, secure, and fast presentation of our website.

Data Processing Region: Data processing is configured to take place primarily within the AWS EU region (Frankfurt, Germany). However, due to the nature of global Content Delivery Networks (Amazon CloudFront), temporary routing through international edge locations may occur.

4. Data Collection on This Website

Server Log Files

The infrastructure provider (AWS) automatically collects and stores information in so-called server log files, which your browser automatically transmits. These include:

  • Browser type and browser version
  • Operating system used
  • Referrer URL (the previously visited page)
  • Host name of the accessing computer
  • Time of the server request
  • IP address

This data is not merged with other data sources. The processing is based on Art. 6 (1) (f) GDPR to ensure the stability and security of the website.

Global Visitor Counter

This website utilizes a serverless database (Amazon DynamoDB) to operate a real-time visitor counter. When you access this website, a backend call triggers an increment to the counter. No personal data, cookies, or individual IP addresses are stored inside the database for this purpose. Only the absolute total count of page views is updated and displayed.
